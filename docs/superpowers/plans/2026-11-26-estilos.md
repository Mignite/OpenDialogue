# Rediseño de Styles — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hacer que la pestaña Styles muestre el mismo subtítulo que el video y sustituir sus campos de texto por un editor por secciones, sin tocar el modelo ni `ass.rs`.

**Architecture:** `ui/estilos_render.rs` encapsula `build_ass` + `rod_subs::Subtitulos::render` en `render_subtitle`, usado por la tarjeta; el overlay sigue con `refrescar_preview`/`state.layers` para no dibujar dos veces. `fontdb` resuelve fuentes para la UI, `Preferencias` guarda el preset abierto por id.

**Tech Stack:** Rust, egui 0.33, eframe, libass vía `rod-subs`, `fontdb 0.24`, `image`.

**Spec:** `docs/superpowers/specs/2026-11-26-estilos-design.md`

## Global Constraints

- No cambiar `PresetAss`, `Hablante`, `presets_ass.json` ni `crates/core/src/ass.rs`.
- El overlay sigue siendo el render del `.ass` exportado: un solo camino de dibujo.
- Todo valor visual sale de `ui/tema.rs`; todo texto de `textos.rs` en ES y EN.
- Ningún texto <11 px; sin overflow horizontal con el panel a 300 px.
- Escala del preview: `fontsize * (alto_preview / CANVAS.1)`, mínimo 20 px legibles.
- `ctx.set_fonts` una sola vez por lote de fuentes nuevas, nunca por frame.
- Los presets no entran en `Historial`; la asignación a selección sí, en un paso.
- Verificación por tarea: `cargo fmt --check`, `cargo clippy -D warnings`, `cargo test --workspace`.

## Review Focus

- Preset con fuente instalada: el bitmap de la tarjeta y el de una línea equivalente del overlay deben ser byte-idénticos. → Task 1, `preview_y_overlay_son_byte_identicos`.
- Fuente ausente: chip ámbar y bitmap de fallback sin pánico. → Task 2, `fuente_ausente_muestra_chip_y_renderiza`.
- Preset con `alignment = 8`: la etiqueta dice `Margin V`, no «Bottom margin», y el `.ass` no cambia. → Task 3, `alignment_8_no_se_fuerza_y_etiqueta_es_generica`.
- Familia sin cara bold/italic: toggles deshabilitados. → Task 3, `toggle_bloqueado_sin_variante`.
- Panel a 300 px: ningún control a media columna ni overflow. → Task 4, `sin_overflow_a_300px`.
