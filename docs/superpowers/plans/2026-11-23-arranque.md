# Arranque Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sustituir el arranque sembrado por un menú de inicio con recientes, apertura de video/proyecto y recovery, sin consola en release.

**Architecture:** `rod-app` pasa a tener un enrutador delgado en `main.rs` con `enum Pantalla { Inicio, Editor }`. El editor actual se mueve íntegro a la librería como `editor_app.rs`; el menú vive en `inicio.rs`, los recientes en `recientes.rs` y las miniaturas en `thumbnail.rs`. El arranque no construye player.

**Tech Stack:** Rust 2024, iced 0.14, `rfd` 0.15, `image` 0.25, `serde_json`, `rod-core`.

**Spec:** `docs/superpowers/specs/2026-11-23-arranque-design.md`

## Global Constraints

- Workspace virtual; paquetes `rod-core`, `rod-subs`, `rod-player`, `rod-app`. Nunca un paquete llamado `core`.
- Sin `unsafe`, macros complejas ni crates nuevos fuera del spec. `image` ya está en el árbol: pasa de `dev-dependencies` a `dependencies`.
- Windows y Linux deben compilar. Cada tarea cierra con `cargo build`, `cargo fmt --all -- --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test --workspace`.
- Sin emojis: iconos con `Canvas` o ASCII. Sin estilo: widgets por defecto, ventana 1600×900.
- El `.cdp` sigue siendo JSON con las claves del oráculo. El `playhead` ya se escribe y se restaura: no se añade campo.
- Las decisiones no obvias se anotan en `BITACORA.md` si desvían del spec padre.

## Review Focus

- Un `.cdp` de recientes borrado o movido: no debe abrir un editor a medias ni dejar una entrada muerta → test `metadata_omite_proyecto_inexistente` (Task 2).
- `recientes.json` corrupto: debe dar lista vacía, no crash → test `indice_roto_da_lista_vacia` (Task 2).
- Más de 10 proyectos guardados y rutas repetidas: tope y dedup → test `registrar_dedup_y_tope` (Task 2).
- PNG de miniatura ausente: placeholder y regeneración al abrir, nunca al arrancar → test `leer_devuelve_none_si_falta` (Task 3) y `abrir_reciente_sin_miniatura_regenera` (Task 6).
- Guardar con el playhead en un segundo concreto: imagen y reanudación deben salir del mismo valor → test `guardar_registra_imagen_en_el_playhead` (Task 6).
